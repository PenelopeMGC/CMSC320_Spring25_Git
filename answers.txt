
Q1: Why might we consider using Git?

Answer: We may consider using Git due to its usefullness when multiple people want to work on code at once. It allows multiple people to change the code in their local repository without altering the main code until nesscary. 

Q2: What field could data science be applied to? Give an Example.

Answer: Data science could be applied to the field of finance to gather crucial financial data to better serve clients. As an example, if a wealth management firm wants to give accurate advice concerning cost of living for those looking to retire, they can use data science to give an informed guess on what the cost of living will be like based on historic data.
