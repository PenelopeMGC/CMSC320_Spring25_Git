Answer: We may consider using Git due to its usefullness when multiple people want to work on code at once. It allows multiple people to change the code in their local repository without altering the main code until nesscary.

Q3: What is the difference between Merging and Rebasing?

Answer: Merging is a non-destructive operation, which merges the history of a main and another branch without changing the existing branches. Rebase takes the main branch and the other branch and rewrites both into one branch, the history is tampered with making it difficult to recover because new commits are made for each commit.
Source: https://www.atlassian.com/git/tutorials/merging-vs-rebasing
